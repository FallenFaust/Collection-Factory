# Style Bible

> Машиночитаемый стайлгайд. Источник — 150+ референсных карточек из ТЗ.
> Этот файл читают шаблоны промптов (`prompts/`) и судья (`pipeline/judge.py`).
> **Версионируется.** Любое изменение — новый коммит с обоснованием в `experiments.md`.

---

## 1. Рендер

| Параметр | Значение |
|---|---|
| Техника | Стилизованный 3D-рендер, «мобильный casual», не фотореализм и не плоский вектор |
| Поверхности | Глянцевые, с мягким specular-бликом; матовые только для ткани/дерева |
| Формы | Утолщённые, скруглённые, «пухлые». Острых тонких элементов нет |
| Свет | Мягкий key сверху-спереди + rim-light по контуру объекта |
| Тени | Мягкая контактная тень под объектом (для категорий 2–4) |
| Насыщенность | Высокая, но без клиппинга. Цвета «конфетные» |
| Контур | Нет обводки. Объект отделяется от фона за счёт светлоты и rim-light |
| Камера | 3/4 сверху, лёгкая перспектива. Фронтальная плоская подача — брак |
| Детализация | Низкая. Крупные читаемые массы. Мелкая текстура запрещена |

## 2. Композиция

- Формат: квадрат 1:1.
- Объект занимает **60–75% высоты кадра**, центрирован по горизонтали.
- Оптический центр объекта чуть выше геометрического центра кадра.
- Поля: не меньше 8% от стороны с каждого края. Объект не касается краёв.
- **Один объект в кадре.** Допустимы 1–2 подчинённых элемента, если они физически часть композиции (напр. попкорн, высыпающийся из ведра).

## 3. Фон

- Фон — часть категории (см. `categories.json`), не свободный параметр.
- Фон **всегда** контрастирует с объектом по светлоте.
- Внутри одного сета из 10 карточек фоновые цвета **распределяются заранее** (см. §6), а не отдаются на волю модели.

## 4. Палитра

Базовые фоновые тона (HEX — ориентир для постобработки, не для промпта):

| Роль | Тона |
|---|---|
| Тёплые | `#F2A03D` оранжевый, `#E8452C` красный, `#F5C518` жёлтый |
| Холодные | `#2E8BC0` синий, `#1FA97A` зелёный, `#7B4FC9` фиолетовый |
| Акцент | `#E84E9E` розовый, `#00BFC6` бирюзовый |

Правило: фон одного семейства — объект контрастного.

## 5. Жёсткие запреты

Нарушение = автоматический реджект судьёй, без обсуждения.

- ❌ Любой текст, буквы, цифры, надписи, логотипы в изображении
- ❌ Узнаваемая интеллектуальная собственность (франшизы, бренды, реальные люди)
- ❌ Мелкие детали, которые схлопнутся в кашу при 100×100 px
- ❌ Фотореализм, «кинематографичный» грейдинг, плёночное зерно
- ❌ Несколько равнозначных объектов, коллаж, сетка
- ❌ Обрезанный объект, объект на краю кадра
- ❌ Тёмная, десатурированная или «грязная» картинка
- ❌ Watermark, рамка, паспарту, тень от рамки

## 6. Раскладка сета (10 карточек)

Обязательное распределение по категориям (см. `categories.json`):

| Категория | Карточек |
|---|---|
| 1 — объект в воздухе, плоский фон | 2 |
| 2 — объект на поверхности, простой фон | 3 |
| 3 — объект на реалистичной поверхности, объёмный фон | 3 |
| 4 — объект в реалистичной среде | 2 |

Фоновые цвета: не более 2 карточек с одним семейством тонов подряд; в сете присутствуют минимум 4 разных семейства.

## 7. Порог читаемости

Финальная проверка каждой карточки: **уменьшить до 100×100 px**. Если объект не опознаётся с первого взгляда — реджект вне зависимости от остальных оценок.
